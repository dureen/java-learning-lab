# Java Learning Lab

Hands-on Java tutorial repository divided into **Beginner**, **Intermediate**, and **Advanced** levels.

**Last updated:** October 1, 2026

Each lesson contains:
- Clear explanation
- Runnable example code
- Practice exercises
- Corresponding unit tests (in `/tests`)

## Structure

```
java-learning-lab/
├── beginner/          # Fundamentals
├── intermediate/      # Intermediate concepts
├── advanced/          # Advanced topics
├── exercises/         # Extra practice exercises
├── tests/             # Unit tests
└── projects/          # Small complete projects
```

## How to use

1. Clone the repository
2. Make sure you have JDK 17+ installed
3. Go into any lesson folder and compile + run the Java files
4. Run tests with your preferred test runner (JUnit 5 recommended)

```bash
git clone https://github.com/dureen/java-learning-lab.git
cd java-learning-lab

# Example: run a beginner lesson
cd beginner/01-hello-world
javac Main.java
java Main
```

## Requirements

- JDK 17 or higher
- (Optional) Maven or Gradle for larger projects and tests
